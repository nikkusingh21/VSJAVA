🧠 Neural Network Architecture Flow

1. Input Text: Raw customer ticket string
2. NLP Cleaning: Lowercase, Mask [URL], [EMAIL], [AMOUNT], [REF], Whitespace tokenization
3. Embedding Layer: 128-dimensional dense word representations
4. Bidirectional LSTM: 2 Layers (128 hidden_dim each direction, Dropout = 0.3)
5. Self-Attention Pooling: Dynamically scores and pools hidden states across full sequence
6. Classifier Head: LayerNorm ➔ ReLU ➔ Dropout ➔ Linear(8 classes)
7. Output Softmax: Calibrated probability scores across all 8 enterprise categories
